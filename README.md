# Oʻzbekiston Respublikasi Fuqaroligiga Qabul Qilish Tizimi

Ushbu loyiha Oʻzbekiston Respublikasining "Fuqarolik toʻgʻrisida"gi Qonunining 18, 19, 20, 21 va 22-moddalariga asoslangan holda fuqarolikka qabul qilish tartiblarini va talablarini aniqlovchi interaktiv vositadir.

## Qonuniy Asoslar
- **18-modda:** Qabul qilish turlari (Umumiy, Soddalashtirilgan, Alohida).
- **19-modda:** Umumiy tartib shartlari (5 yil uzluksiz yashash, til bilish, daromad va h.k.).
- **20-modda:** Vatandoshlar uchun soddalashtirilgan tartib va kafolat xati qoidalari.
- **21-modda:** Prezident tomonidan milliy manfaatlardan kelib chiqib alohida tartibda berilishi.
- **22-modda:** Fuqarolikka qayta tiklash tartibi.
